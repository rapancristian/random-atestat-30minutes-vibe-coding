IMPROVED PROMPT:

I want you to create a complete web project, built only with HTML, CSS, and vanilla JavaScript, without frameworks, about video games. The project must be modern, clean, visually appealing, and easy to navigate. There is no previous context, so treat everything as a new project built from scratch.

Project goal

The site should be a simple and modern platform dedicated to gaming, where users can discover video games, events, guides, gaming platforms, and community opinions.

General requirements
Use only:
HTML
CSS
vanilla JavaScript
Responsive design, so it looks good on desktop, tablet, and phone
Modern visual style inspired by gaming:
strong but pleasant colors
good contrast
clearly separated sections
elegant cards
hover effects
buttons and subtle animations
All content must be strictly about video games
I do not want anything related to sports, football, or any other domain
If needed, you may invent realistic content for examples
I also accept creative recommendations to make the site more interesting, but keep the project simple and clear
Site structure

The site must have a main navbar with the following tabs:

Home
Video Games
Event
Guide
Gaming Platforms
Community
Home page

The home page must contain:

1. Hero / main banner
a large, visually attractive banner
theme: latest released games / new popular games
on the left or in the background there can be a relevant gaming image
on the right there should be:
a large title
a descriptive text about the world of video games
a button like "Explore now" or "See games"
2. Recommended games section
at least 3 cards
each card should have:
image
game title
genre
short description
a "Details" button
3. Latest news section
small cards or information blocks about releases, updates, DLCs, or gaming trends
4. Footer
site name
quick links
copyright
optional social media icons
The "Video Games" page

This page should present popular games.

Requirements:
displayed as cards
at least 6 games
each game should have:
image
title
category/genre (RPG, FPS, Open World, Racing, etc.)
short description
rating or popularity
you may add a simple JavaScript filter by category if you want to make the page more interactive
The "Guide" page

When the user clicks the Guide tab, a separate page will open.

This page must contain 3 large sections, each with a clear heading and examples:

1. BEGINNER TUTORIALS
explanations for beginners
examples: how to choose your first game, how to learn the controls, how to set your sensitivity, how to start in competitive games
2. STRATEGIES
useful tips for multiplayer or single-player games
examples: resource management, positioning, team tactics, choosing the right character
3. GAMEPLAY
explanations about play styles
examples: stealth, aggressive, defensive, co-op, open world exploration
Recommended design:
each section should be inside a large block/card
icons or suggestive images
clear and airy text
The "Gaming Platforms" page

When the user clicks the Gaming Platforms tab, a separate page will open.

This page should describe two major platforms:

Steam
Epic Games Store
For each platform:
logo or representative image
short description
advantages / what makes it popular
at least 2 popular games available on that platform
for each game:
name
short description
approximate price
Example structure:
Steam section
description
game 1 + price
game 2 + price
Epic Games section
description
game 1 + price
game 2 + price

You can use approximate realistic or invented prices, as long as they seem believable.

When the user clicks the Community tab, a separate page will open.

This page must contain a slider/carousel with community reviews.

Requirements:
at least 4-5 reviews
each review should have:
user name
avatar or placeholder image
the game they are talking about
rating
short review text
the slider should be made in vanilla JavaScript
it should have Next / Prev buttons
optional: autoplay or indicators/dots
Style:
modern testimonial-style section
friendly and dynamic design

event title
image

date
button or the ability to click the card

game launches
